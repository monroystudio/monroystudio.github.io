# Monroy Studio — official website

English informational website for the Monroy Studio project, hosted at https://monroystudio.github.io/.

The Windows Desktop app and TikTok integration are future projects. This repository provides no application download, accounts, OAuth connection, video upload or publishing service. It does not claim TikTok approval or endorsement.

The website uses static HTML, CSS and local images with system fonts. It has no JavaScript, contact forms, analytics, cookies or browser storage implemented in its code. GitHub Pages hosting and Gmail correspondence are described in the Privacy Policy.

## Pages and assets

- `index.html`: project description, planned workflow and FAQ.
- `terms.html`, `privacy.html`, `contact.html`: website terms, privacy notice and official contact.
- `404.html`: custom missing-page response.
- `styles.css`, icons and artwork: local visual resources.
- `.nojekyll`, `robots.txt`: static hosting configuration.

No package installation or build step is required. GitHub Pages serves the root of `main`. Check the actual Pages source in repository settings before changing deployment configuration. Use HTTPS and verify the home page, legal pages, contact, icons and custom 404 after each deployment.

The legal documents become effective on their actual first publication date. Later versions must carry their effective date and communicate material changes as described in the notice.

Keep credentials, private correspondence, privacy-request records, internal procedures, downloads, exports and backups outside this public repository. `.gitignore` is a convenience, not an access control or a secret scanner. This website does not launch the future application or request TikTok production review.
